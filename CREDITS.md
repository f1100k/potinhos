# Créditos

## Sons

Todos os sons de `public/sounds/` foram gravados e editados para o projeto, sem material de terceiros. Os arquivos originais ficam em `sounds-src/`. Os de `public/sounds/` saem deles com o chiado de fundo reduzido (passa-altas em 90 Hz e `afftdn` do ffmpeg), o volume equalizado (o trecho mais alto de 50 ms de cada um em −30 dBFS) e convertidos para MP3, 128 kbps. O `draw-rustle.mp3` sai de `sounds-src/rustle.ogg`, só com o volume equalizado, sem redução de ruído.

| Arquivo | Quando toca |
| --- | --- |
| `draw-rustle.mp3` | Sorteio: o pote balança |
| `draw-unfold.mp3` | Sorteio: o papelzinho se desdobra |
| `done-fold.mp3` | Concluí: o papelzinho se dobra |
| `done-tap.mp3` | Concluí: o "toc" ao cair no pote de conquistas |
| `slip-drop-2.mp3`, `slip-drop-3.mp3` | Nova semana: cada papelzinho caindo no pote Semanal, alternando os dois. O `slip-drop-2` também toca em "Não consegui hoje", quando o papelzinho volta ao pote |
