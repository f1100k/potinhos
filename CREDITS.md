# Créditos

## Sons

Todos os sons de `public/sounds/` foram gravados e editados para o projeto, sem material de terceiros. Os arquivos originais (antes da conversão para MP3, 128 kbps) ficam em `sounds-src/`.

| Arquivo | Quando toca |
| --- | --- |
| `draw-rustle.mp3` | Sorteio: o pote balança |
| `draw-unfold.mp3` | Sorteio: o papelzinho se desdobra |
| `done-fold.mp3` | Concluí: o papelzinho se dobra |
| `done-tap.mp3` | Concluí: o "toc" ao cair no pote de conquistas |
| `return-rustle.mp3` | Não consegui hoje: o papelzinho volta ao pote |
| `slip-drop-1.mp3`, `slip-drop-2.mp3`, `slip-drop-3.mp3` | Nova semana: cada papelzinho caindo no pote Semanal |

## Fonte

Varela Round, de Joe Prince, sob a SIL Open Font License 1.1, distribuída pelo pacote `@fontsource/varela-round`.
